## Аудит протокола
- ProtocolEligibilityVerifier использует снимок заявки, не текущий профиль.
- BY_YEAR = опорный год минус год рождения; ON_DATE = полные годы на опорную дату.
- ProtocolCategoryPolicy требует ровно одну совпавшую категорию.
- PrepareStartProtocol делит участников по seedingGroupCode до выполнения правил по группам.
- categoryCode/seedingGroupCode сохраняются в назначениях.
- Привязанная конфигурация регламента возвращается на уровне мероприятия.
- Совпадение категории не доказывает допуск к конкретной дистанции/стилю/полу дисциплины.
- CreateEventDisciplineUseCase создаёт дисциплины только в DRAFT-мероприятии.
- Переданный settingsJson заменяет defaultMeta шаблона, а не дополняет его.

## Текущий патч: только отображение
- Параметры дисциплины из settingsJson.
- Категории и группы из загруженной конфигурации.
- Предварительная проверка категорий по снимкам подтверждённых заявок.
- Сохранённые категории отдельно от предварительной проверки.
- Заявочное время из заявки отдельно от seedMetric в ответе протокола.
- Ни backend, ни правила генерации, ни записи БД не меняются.
